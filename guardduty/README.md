## GuardDuty CloudFormation

### GuardDuty - Runtime Monitoring (EC2)

Enables Runtime Monitoring with automated security agent management for EC2 (GA 2024-03-29), prepares instances for the agent, and owns the `guardduty-data` VPC endpoint so VPC stacks stay deletable. Covers the `GuardDutyManaged` inclusion/exclusion tag, coverage status alerting, and the `*:Runtime/*` finding types.
