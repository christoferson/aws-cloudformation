# Configuring Amazon EventBridge

Use EventBridge to detect and react to changes for AWS Health events. You can monitor specific AWS Health events that occur in your account, and then set up rules so that AWS Health notifies you, or you take action, when events change.Use EventBridge with AWS Health
Open your AWS Health Dashboard at https://health.aws.amazon.com/health/home.
To navigate to the EventBridge console to create a rule, do one of the following:  
From the navigation pane, under Health Integrations, choose Amazon EventBridge.  
Under Configure EventBridge, choose Go to EventBridge.  
Follow this procedure to create rules and monitor for events. See Monitoring events in AWS Health with Amazon EventBridge.
